7. Md5 used as password

MEDIUM · line 31 · found by Semgrep · CWE-327: Use of a Broken or Risky Cryptographic Algorithm

MD5 is a weak hashing algorithm that is easily cracked using modern hardware and rainbow tables. Passwords should instead be hashed using strong, slow hashing functions like bcrypt or Argon2.

Problem code

Suggested fix
